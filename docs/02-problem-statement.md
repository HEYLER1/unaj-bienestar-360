# 02 · Problema y evidencia

**Verificado:** el portal UNAJ describe servicios de bienestar y anuncia SIGBU; ver investigación.

**Problemas preliminares aportados por el solicitante, no observados por este proyecto:** formularios manuales, esperas, desperdicio, demanda desigual y dispersión de información.

**Pendiente de validar:** entrevistar responsables por servicio; observar tiempos y aforos sin recoger datos sensibles; revisar procedimientos vigentes; establecer línea base. No atribuir fallas a SIGBU ni asumir ausencia de digitalización.

**Propuesta:** centralización de reservas, trazabilidad operativa y acciones de mejora, sujeta a validación institucional.
