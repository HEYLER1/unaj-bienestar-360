# 05 · Partes interesadas

Estudiantes; personal médico, psicológico, enfermería, nutrición y odontología; trabajo social; operadores de comedor y gimnasio; coordinaciones deportiva y cultural; dirección de bienestar; calidad; tecnología y privacidad.

Matriz propuesta: estudiante gestiona sus reservas; operador gestiona únicamente su dominio; calidad gestiona mejoras; coordinación observa indicadores agregados; técnico administra infraestructura sin acceso clínico. El perfil Gestión demo reúne permisos operativos explícitos para facilitar la exposición. No representa segregación de funciones de producción.

Pendiente: designación institucional de responsables, entrevistas, validación de matriz, autorización de acceso por profesional y recurso.
