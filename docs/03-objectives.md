# 03 · Objetivos

Objetivo general: demostrar procesos administrativos de bienestar con reservas consistentes y mediciones verificables.

1. Evitar sobrecupos y duplicados en el flujo implementado.
2. Restringir operaciones por actor y recurso en el servidor.
3. Distinguir asistencia, entrega, producción y desperdicio.
4. Documentar una ruta de migración y validación hacia Supabase.
5. Vincular acciones correctivas a evidencia de ejecución y eficacia.

Los valores objetivo institucionales se definirán con responsables; no se inventan porcentajes ni líneas base.
