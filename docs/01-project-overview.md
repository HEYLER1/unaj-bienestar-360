# 01 · Visión del proyecto

Centralizar la gestión administrativa de bienestar universitario como propuesta académica ampliable. Usuarios: estudiantes ficticios, operadores de servicios, coordinación y calidad. La UNAJ anunció SIGBU; esta propuesta no lo sustituye ni presupone sus limitaciones.

La implementación inicial es local, de un solo proceso y con SQLite. La arquitectura destino es Next.js + PostgreSQL/Supabase. No se utilizan datos personales reales.
